# Changelog

## 0.1.0

Initial public release.

- Parse the public UCI 2.6 XSD into a stable model.
- Generate typed Rust bindings with unknown-safe enums.
- Validate JSON messages with stable error codes and paths.
- Diff UCI 2.5 to 2.6 and classify compatibility.
- Build a static reference site for 2.6 and 2.5.
- Run scripted task and signal scenarios against Sleet or an in-process broker.
- Fuzz the parser.
- Enforce 95% total line coverage and 95% changed-line coverage.
- Publish cross-platform release binaries from CI.

Not certified, not operational, and not affiliated with the U.S. Air Force.
