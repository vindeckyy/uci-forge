# Security

## Scope

UCI Forge handles public Distribution A schema data. It does not process Controlled
Unclassified Information, classified data, or restricted standards.

## Reporting

Report a vulnerability through GitHub Security Advisories on this repository. Do not
open a public issue for a vulnerability.

Include:

- The affected crate or command.
- A minimal reproduction.
- The impact you observed.

There is no bug bounty. Good reports get credit in the advisory unless you ask to
remain anonymous.
